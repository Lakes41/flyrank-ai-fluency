# AI Fluency Track Portfolio

This repository is my personal workspace for documenting my work throughout the FlyRank AI Fluency Track. It serves as a structured record of my learning journey, assignments, experiments, and practical applications of AI in data-driven work.

## Purpose

The goal of this repo is to capture and organize:

- AI Fluency track assignments and deliverables
- Workflow audits and reflections on how I use AI in data science tasks
- Data analysis, experimentation, and project notes
- Documentation of tools, processes, and insights gained along the way
- A growing portfolio of work that demonstrates my progress and capability in applying AI effectively

## What this repository contains

This project is intended to hold the materials related to my internship and learning experience, including:

- assignment write-ups
- task breakdowns and workflow documentation
- analysis notes and findings
- code, scripts, and supporting resources
- reflections on ethical, practical, and business considerations in AI use
